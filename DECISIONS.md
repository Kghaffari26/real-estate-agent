- Metro prompts and guards use the facts minus `rates`/`affordability` (the same dict that's hashed): §10 requires briefs never quote payment figures that would go stale, and a rate-only change must not regenerate metro briefs; §7.2's dict still carries those fields for the national/affordability side.

- An unusable single LLM response (`LLMError`: refusal/truncation/schema mismatch) falls back to the template instead of failing the run; API/auth errors and `BudgetExceeded` still fail it (CLAUDE.md: the LLM path has no optional-source exemption).
